## Short description
Review-first WordPress translation workflow for agencies: visual editing, AI-assisted batches, CSV/XLIFF, SEO metadata and usage reporting.

## Short pitch
Webactueel Translate helps WordPress teams translate frontend content with manual control, visual editing, CSV/XLIFF workflows and optional AI-assisted batches.

## Long description
Webactueel Translate is built for review-first multilingual WordPress workflows. Scan frontend-visible content, translate manually or with AI assistance, review quality and context warnings, then publish approved translations with more control.

The plugin is designed for agencies and content teams that need practical workflows instead of a black-box instant translation layer. It supports visual editing, dedicated translator capabilities, CSV/XLIFF roundtrips, glossary-aware AI translation, SEO metadata translation foundations, WooCommerce-aware safe-mode behavior and exportable AI usage reports.

AI translation is optional and disabled by default. API keys should be supplied through server constants or filters where possible. Database credential storage is opt-in only, so agencies can keep client setups more controlled.

## Key features
- Review-first translation workflow with statuses and publication checks.
- Visual frontend editor for editing translated strings in context.
- Dedicated translator role/capability for agency teams.
- Optional AI-assisted batches for OpenAI, DeepL and compatible providers.
- Glossary-aware AI translation and Translation Memory reuse.
- CSV and XLIFF import/export for backup and professional translation workflows.
- SEO metadata support for Yoast, Rank Math, AIOSEO and SEOPress workflows where configured.
- Hreflang, canonical and sitemap foundations.
- WooCommerce-aware frontend replacement guards and safe-mode behavior.
- AI usage ledger/export for client reporting and rebilling support.
