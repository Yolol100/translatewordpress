# Security Policy

## Supported versions

Security updates are provided for the latest released version of Webactueel Translate.

## Reporting a vulnerability

Please do not open public GitHub issues for security reports.

Email security reports to: andrew@webactueel.nl

Include:
- affected version
- WordPress and PHP version
- steps to reproduce
- expected and actual behavior
- any relevant logs or screenshots without secrets/API keys

We aim to acknowledge valid reports as soon as possible and will coordinate a fix before public disclosure.
